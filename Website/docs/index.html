1. 基本モデル

  • コンパイルは Editor 上で 1 回だけ行います。レイアウトを計算し、その結果を RectTransform の固定値として焼き込みます。実行時にレイアウトを計算し直すことはありません。
  • 出力されるのは素の uGUI / TextMeshPro の階層です。Rectloom のランタイムコンポーネントは含まれません。
  • body の箱が Canvas になります。html と head はパース時に取り除かれます。
  • 状態に依存する表現 (:hover、アニメーション、スクリプト) は出力に残りません。
  • 既定のボックスモデルは box-sizing: border-box です。
  • マージンの相殺 (margin collapsing) は行いません。縦に並んだ箱のマージンは足し算になります。

9. 独自プロパティ

unity- と vrc- で始まる名前は予約済みのプレフィックスです。コアはこれらの値を解釈せず、そのまま各アダプタへ渡します。外部ライブラリ向けの拡張は <library>- の形のプレフィックスを使います。

unity- (uGUI バックエンド)

プロパティ値既定値効果
unity-raycast-targettrue / falsebutton・input は true、それ以外は falseGraphic の raycastTarget を設定します。
unity-interactabletrue / falsetrueButton・Toggle・Slider の interactable を設定します。HTML の disabled 属性も false にします。

vrc- (VRChat アダプタ)

body のルールに書いてください。VRChat アダプタを導入していないプロジェクトでは読み飛ばされます。

プロパティ値既定値効果
vrc-world-spacetrue / falsetrueCanvas を World Space にします。Screen Space の Canvas は他のプレイヤーからは見えず、VR でも表示されません。
vrc-world-scale数値0.0011 論理 px あたりのワールド単位です。0.001 なら幅 1920px が約 1.92m になります。
vrc-ui-shapetrue / falseウィンドウの設定に従う (既定 on)VRCUiShape を付けると、プレイヤーがポインタで指してクリックできるようになります。Worlds SDK がない場合、Canvas が World Space でない場合、別の Canvas の下にある場合は付けません。既存の VRCUiShape を削除することもありません。
vrc-interacttrue / false—名前だけ予約されています。現時点では効果がありません。
 
body {
  vrc-world-space: true;
  vrc-world-scale: 0.001;
  vrc-ui-shape: true;
}

知らない vrc- プロパティを書くと VRC1004、値が読めないと VRC1003 になります。

10. component 属性と Udon 属性

component 属性

<button id="apply"
        component="Example.CustomButton"
        component.mode="Primary"
        component.speed="1.5">Apply</button>
  • component には型名を書きます。エイリアス → 完全名 → 短い名前の順に探します。短い名前に一致する型が複数あると EXT1002 になります。対象は Component の派生型だけです。
  • component.<名前> の値は、シリアライズされたフィールド (名前、または m_名前) に書き込みます。フィールドが見つからないと EXT1004 です。
  • 書き込める型: bool、int、float、string、char、enum、Color、Vector2/3/4、Rect、アセット参照。それ以外の型は EXT1005 になります。
  • HTML の属性名は小文字に変換されるため、component.blocksRaycasts のように大文字を含む名前は指定できません。1 単語の名前だけ使えます。
  • そのコンポーネントがまだ付いていなければ追加します。Editor 専用アセンブリにある型は追加できません。
  • 処理を担当する Extension (IHtmlUiExtension) がプロジェクト内にあれば、その Extension に渡されます。Extension は存在するだけで自動的に使われます。例は Core パッケージのサンプル Extension Example を参照してください。

VRChat Udon 属性 未リリース

VRChat アダプタと Worlds SDK が必要です。

<div id="door-panel" vrc-udon="./DoorPanel.asset">
  <button vrc-event="Open">開ける</button>
  <input type="checkbox" vrc-event="ToggleLight">
  <input type="range" vrc-event="SetVolume" vrc-target="#audio">
</div>
属性対象意味
vrc-udon全要素要素の GameObject に UdonBehaviour を付け、program を設定します。値には Udon program asset (Udon Graph / UdonSharp)、または UdonSharp のスクリプトを指定します。指定方法は HTML からの相対パス、Assets/ からのパス、GUID のいずれかです。
vrc-eventbutton / checkbox / rangeonClick (button) または onValueChanged (checkbox・range) に UdonBehaviour.SendCustomEvent("<名前>") を登録します。
vrc-targetvrc-event を持つ要素イベントの受け手を指定します。#id は文書内の要素、/Path/In/Scene はシーン上のオブジェクトです (シーンに出力するときだけ使えます)。省略すると、自分自身から祖先へ向かって最初に UdonBehaviour を持つ要素が受け手になります。
  • 呼び出すメソッドは SendCustomEvent に固定されています。マークアップで選べるのはイベント名と受け手だけで、任意のメソッドは呼べません。
  • Inspector で手動追加した UdonBehaviour も受け手にできます。Update 後も保持されます。
  • metadata に記録されるのはコンパイラが追加したリスナーだけで、次回のコンパイルではそれだけを差し替えます。手で追加したリスナーは削除しません。
  • vrc-udon を削除しても、追加済みの UdonBehaviour は削除しません。Inspector で public 変数を設定している可能性があるためです。
  • 失敗すると VRC1006 (Warning) が出ます。Worlds SDK が入っていないのにこれらの属性があると VRC1005 (Warning) が出ます。

11. 画像とアセット参照

<img src="…"> と CSS の url("…") で、次の形式の参照を書けます。

形式例
相対パス (書いたファイルからの相対)./images/icon.png
プロジェクトパスAssets/UI/icon.png
GUIDアセットの GUID
data: URIdata:image/png;base64,…
  • data: URI で書ける形式は png、jpeg、gif、bmp、tga (base64)、svg+xml (base64 と UTF-8) です。
  • 埋め込み画像は <出力フォルダ>/Embedded/ にアセットとして書き出します。ファイル名は内容のハッシュなので、同じ画像は 1 つのアセットにまとまります。
  • SVG は Vector Graphics パッケージで PNG にラスタライズします。解像度は既定で 2px / 論理 px、1 辺の上限は 4096px です。インラインの <svg> 要素には対応していないので、<img src="data:image/svg+xml,…"> の形で書いてください。
  • 読めない画像があっても文書全体の生成は止まりません。その画像の箱は空 (透明) のまま残り、Warning が 1 件出ます。Strict Mode では Error になります。
  • HTTP(S) の URL は参照できません。

12. フォントと絵文字

  • font-family のリストを先頭から順に調べ、最初に見つかった TMP Font Asset を使います。
  • 照合する対象はアセット名とフォントのファミリー名で、どちらも小文字化して英数字以外を取り除いてから比べます。完全一致を優先し、なければ前方一致を使います。そのため "Noto Sans JP" は NotoSansJP-Regular SDF に一致します。
  • 総称ファミリー (sans-serif など) は Default TMP Font として扱います。リストの途中に総称ファミリーがあると、その後ろの候補は調べません。
  • どの候補も解決できないと Warning が 1 件出ます。
  • フォントにない文字は「どのフォントにどの文字 (U+XXXX) がないか」を 1 件だけ報告します。フォント自身のフォールバックと、TMP Settings の Fallback Font Assets も調べたうえで判定します。
  • 絵文字は font-family とは別に、Emoji TMP Font (既定は Segoe UI Emoji) で描きます。プロジェクトにそのフォントのアセットがなければ、インストール済みのフォントをプロジェクトにコピーしてから生成します。カラー絵文字は TMP の Sprite として出力されます。
  • プロジェクトにコピーしたフォントはビルドに含まれるので、ライセンスを確認してください。
  • TMP Essential Resources が必要です (Window > TextMeshPro > Import TMP Essential Resources)。

13. Update コンパイル

  • Update モードでは、前回の出力と metadata アセットを使って差分だけを適用します。要素の照合には id を使います。
  • コンパイラが書き換えるのは、自分で生成したプロパティだけです。Button.onClick などの UnityEvent と、手で追加したコンポーネントは保持されます。
  • 手を加えた生成オブジェクトが HTML から消えた場合は、オブジェクトを残して UNITY1006 を出します。保持の設定を切っている場合は削除して UNITY1007 を出します。
  • metadata がないと、どこがユーザーの変更か判断できないため、更新を拒否します (UNITY1008)。Create で既存の出力に上書きしようとすると UNITY1005 です。
  • Extension が追加したコンポーネントは metadata に記録されないため、ユーザーが追加したものとして扱われ、Update で削除されません。

15. 非対応の機能

  • レイアウト: float、grid、table、インライン整形、マージンの相殺
  • 要素: フォーム部品 (checkbox・range 以外の input、select、textarea)、インラインの <svg>
  • CSS: calc()、vw/vh、グラデーション、box-shadow、transform、辺ごとの border-*、角ごとの border-radius
  • 動的な機能: 擬似クラス、アニメーション、スクリプト、スクロール
  • 外部参照: HTTP(S) の画像やフォント

対応している機能をひととおり使った見本として、uGUI パッケージのサンプル Feature Showcase があります。
