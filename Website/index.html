Rectloom

HTML/CSS を Unity uGUI へコンパイルする Editor ツールの VPM リポジトリです。

VCC への追加

VRChat Creator Companion の Settings → Packages → Add Repository に次の URL を入力します。

https://chikumatateshina.github.io/Rectloom/index.json

導入手順

  1. 上の URL を購読します。
  2. ワールドプロジェクトの Manage Project を開きます。
  3. Rectloom for VRChat を追加します。Core と uGUI Backend は依存として入ります。
  4. Unity で Tools → Rectloom → Compiler を開きます。

パッケージ

Package内容
com.chikumatateshina.rectloom.coreパーサー、CSS、レイアウト、IR
com.chikumatateshina.rectloom.uguiuGUI / TextMeshPro バックエンド
com.chikumatateshina.rectloom.vrchatVRChat アダプタ

ワールドビルドへの影響

ありません。全アセンブリが Editor 専用で、コンパイル記録も Editor 専用アセットです。 生成物は通常の uGUI オブジェクトなので、ワールドビルドに Rectloom のコードは含まれません。
