Rectloom

HTML/CSS から、ワールドに置ける Unity UI を。

展示のキャプション、入口の案内、イベントの情報パネル。 文章とレイアウトを HTML/CSS で用意して、Unity の UI と Prefab に変換できます。 生成した UI は Scene に配置し、通常の Unity オブジェクトとして編集できます。

Rectloom とはユースケース VCC に追加使い方フォントと画像

Rectloom とは

Unity Editor 上で HTML/CSS を読み取り、Canvas、TextMeshPro、Image、Button などを 組み合わせた UI を生成するツールです。生成後は HTML を実行せず、普通の uGUI として動作します。 VRChat ワールドの空間に置くパネルにも、通常の Unity の画面 UI にも使えます。

HTML / CSS文章・色・レイアウトを用意
→
Unity UI / PrefabScene に置いて使う

同じ見た目のパネルをまとめて作り、内容を変更したら再コンパイルして更新できます。 Update は差分を反映し、設定済みのボタンイベントや追加した Component を保持します。 更新を続ける要素には HTML の id を付けておくと、同じ要素として識別できます。

こんな場面に

展示キャプション

作品名、作者、解説、ロゴをまとめたパネルに。 共通の CSS を使い、作品ごとの HTML からそれぞれの Prefab を作れます。

ワールドの案内

入口の説明、利用ルール、エリアの紹介に。 World Space Canvas で生成し、壁や展示台のそばに配置できます。

イベント情報

開催日時、出演者、プログラムの掲示に。 文章を HTML で更新し、既存の Prefab に変更を反映できます。

VCC に追加

VRChat Creator Companion が開き、このリポジトリの追加確認が表示されます。
ボタンが反応しない場合

vcc:// リンクは VCC がインストールされている環境でのみ動作します。 反応しない場合は上の URL をコピーして、手動で追加してください。

  1. VCC を開き Settings を開きます
  2. Packages タブを開きます
  3. Add Repository を押します
  4. コピーした URL を貼り付けて Add を押します
  5. 内容を確認して I Understand を押します

ALCOM を使っている場合は Resources → Repositories → Add Repository から同じ URL を追加してください（ALCOM にワンクリック追加のリンクはありません）。

最初のパネルを作る

Unity 2022.3 と TextMeshPro を使用します。VRChat では VCC で用意したワールドプロジェクトに導入してください。

  1. プロジェクトに Rectloom を入れる

    上のボタンでリポジトリを追加したら、 VCC の Manage Project で Rectloom の + を押し、Unity を開きます。 TMP のリソースが未導入なら、Window → TextMeshPro → Import TMP Essential Resources からインポートします。

  2. HTML を Assets 内に用意する

    文章を HTML、見た目を CSS に記述します。 CSS は HTML 内の <style>、外部 CSS のリンク、Compiler の追加 CSS で指定できます。 まずは下の例を caption.html として保存してみてください。

  3. Compiler で出力を設定する

    Tools → Rectloom → Compiler を開き、 ソース HTML と Default TMP Font を指定します。 Output Folder の Browse から、Assets 内の Prefab 保存先を選びます。

  4. Compile して Scene に置く

    初回は Create でコンパイルします。 HTML と同じ名前の Prefab が出力されるので、Scene にドラッグし、位置と向きを調整してください。 World Space の既定設定では HTML の 1px が 1mm に相当します（親の倍率が 1 の場合）。

  5. 内容を更新する

    HTML/CSS を編集し、Update で再コンパイルします。 一緒に生成される .rectloom.asset は更新用の記録なので、Prefab とともに残してください。 VRChat に反映するには、更新後のワールドをビルド・アップロードします。

コピーして試せる展示キャプション

日本語対応の TMP Font Asset を指定してください。この例のパネルは、既定の World Space 設定で幅 600mm になります。

<!doctype html>
<html lang="ja">
<head>
  <meta charset="utf-8">
  <style>
    body { margin: 0; }
    .caption {
      box-sizing: border-box; width: 600px; padding: 32px;
      background: #202631; color: #ffffff;
    }
    h1 { font-size: 40px; margin: 0 0 16px; }
    p { font-size: 24px; line-height: 1.5; margin: 0; }
  </style>
</head>
<body>
  <article id="caption" class="caption">
    <h1 id="title">星空の記録</h1>
    <p id="description">作者：サンプル<br>夜空を撮影した作品です。</p>
  </article>
</body>
</html>

複数の HTML をまとめて出力するには： Batch HTML files をオンにし、Add HTML file で追加するか、 Project でファイル・フォルダを選択して Add selected HTML files / folders を押します。 Compile All HTML Files で、HTML ごとに独立した Prefab を出力します。

フォントと画像

日本語：Noto Sans JP などから TMP Font Asset を作り、 Default TMP Font に指定します。フォントファイルを Assets に入れ、Project で右クリックして Create → TextMeshPro → Font Asset から作成できます。 Dynamic の場合は、元フォントの Include Font Data を有効にしてください。 既定の LiberationSans には日本語の字形がありません。 最後の字形補完に Meiryo を使う場合は、Meiryo の TMP Font Asset を Project Settings → TextMesh Pro → Fallback Font Assets の末尾に追加します。

絵文字：インストール済みの Segoe UI Emoji がある環境では、対応する絵文字をカラー画像として生成します。 Emoji TMP Font でフォントを明示することもできます。生成 Prefab は絵文字アセットを直接参照します。 単独の Unicode 絵文字が対象で、肌色や ZWJ を使う複合絵文字などは未対応です。

画像・ロゴ：<img> と CSS の背景画像を使えます。 PNG/JPEG のほか、base64 で埋め込んだ SVG をコンパイル時に画像へ変換します。 SVG 内の文字はアウトライン化し、フィルターなど未対応の表現は PNG にしてください。

使う前に知っておくこと

HTML/CSS の対応範囲は、文字・画像・ボックス・Flex レイアウトなどです。 JavaScript、ブラウザ固有の動作、::before / ::after、印刷用ルールは再現しません。 HTML に直接書いた SVG 要素は対象外なので、画像として埋め込んでください。

ボタンの見た目は生成できますが、押したときの動作は Unity のイベントや Udon で設定します。 Rebuild は完全再生成で手作業の設定を失うため、通常の編集には Update を使ってください。

HTML の body のプレビュー背景は既定では出力せず、本文要素の背景を生成します。 ページ全体の背景が必要な場合は Document Background をオンにしてください。 画面用の UI を作る場合は World Space (1px = 1mm) をオフにします。

コンパイル時の診断にソース位置と対処方法が表示されます。擬似要素や印刷ルールのスキップは情報です。 字形不足が出たらフォント設定を確認してください。詳しい対応範囲・設定は README と 導入手順 を参照できます。

ワールドビルドへの影響

Rectloom の処理は Editor 専用で、ワールドビルドにコンパイラのコードは含まれません。 生成した UI と、その画像・フォントなどの参照アセットがワールドに含まれます。 表示に必要な容量や負荷は、パネル数、画像の解像度、使用するフォントに応じて変わります。
