Rectloom

HTML/CSS を Unity uGUI へコンパイルする Editor ツールです。

インストール

VRChat Creator Companion が開き、このリポジトリの追加確認が表示されます。
ボタンが反応しない場合

vcc:// リンクは VCC がインストールされている環境でのみ動作します。 反応しない場合は上の URL をコピーして、手動で追加してください。

  1. VCC を開き Settings を開きます
  2. Packages タブを開きます
  3. Add Repository を押します
  4. コピーした URL を貼り付けて Add を押します
  5. 内容を確認して I Understand を押します

ALCOM を使っている場合は Resources → Repositories → Add Repository から同じ URL を追加してください（ALCOM にワンクリック追加のリンクはありません）。

プロジェクトへの追加と使い方
  1. VCC でワールドプロジェクトの Manage Project を開きます
  2. Rectloom for VRChat の + を押します
    Core と uGUI Backend は依存として自動的に入ります
  3. Unity で Tools → Rectloom → Compiler を開きます
  4. HTML と CSS を指定して Compile します

詳細は 導入手順 を参照してください。

パッケージ

PackageVersion
Rectloom for VRChat com.chikumatateshina.rectloom.vrchat VRChat アダプタ。これを入れれば Core と uGUI も入ります —

Rectloom Core com.chikumatateshina.rectloom.core パーサー、CSS、レイアウト、IR —

VRChat を使わない場合 (UPM)

Packages/manifest.json へ追加します。Core は依存として入ります。

"com.chikumatateshina.rectloom.ugui":
  "https://github.com/ChikumaTateshina/Rectloom.git?path=Packages/com.chikumatateshina.rectloom.ugui"

ワールドビルドへの影響

ありません。全アセンブリが Editor 専用で、コンパイル記録も Editor 専用アセットです。 生成物は通常の uGUI オブジェクトなので、ワールドビルドに Rectloom のコードは含まれません。
