# Architecture Decision Records

設計上の重要な決定と、仕様資料 (`docs/00`–`docs/12`) からの逸脱をここへ記録します。

仕様の優先順位:

1. 資料群の明示的 MUST 要件
2. **ADR で承認された変更**
3. 実装 Issue の Acceptance Criteria
4. コード上の既存挙動
5. 実装者の判断

新しい ADR は [`../12_ADR_TEMPLATE.md`](../12_ADR_TEMPLATE.md) を複製し、
`NNNN-kebab-case-title.md` として追加します。

| ADR | Title | Status |
|---|---|---|
| [0001](0001-rectloom-naming.md) | Rectloom naming for packages, assemblies and namespaces | Accepted |
