# HTML/CSS to Unity UI Compiler — Handoff Pack

Codex等のコーディングエージェントおよび人間のUnity開発者へプロジェクトを引き継ぐための仕様資料群。

最初に `00_INDEX.md` を読むこと。

この資料群は以下を前提とする。

- HTML/CSS → Unity uGUIの静的Editorコンパイル
- JavaScriptなし
- Coreは汎用Unity
- VRChatはAdapter
- 外部UI libraryはExtension
- GitHub / UPM / VPM / VCC公開
- 差分コンパイルによりUnity側のイベント・参照を可能な限り保持
